## Exercise 1

1. Create a subdirectory in your `views` directory that will house a partial template for a nav bar that will be rendered within all of your previously created EJS templates.

2. Create your `nav.ejs` file and add some boilerplate that renders a nav with nested `a` tags.

3. Add an include statement that takes the file you created as an argument and renders it in each template you want to render the nav bar in.

Congrats!! You've rendered a partial in other EJS templates.
